Deep Reinforcement Learning

MARL: Learned Memory Allocation in Heterogeneous Memory Systems

Fall 2021 - CS285 Final Project

  • Problem: Memory wall bottleneck where deep learning demand outstrips DRAM capacity growth
  • Solution: MARL framework with Graph Neural Networks + Evolutionary Algorithms for intelligent DRAM/PM allocation
  • Implementation: Modified PyTorch C++ (6,400+ lines) to intercept memory calls; tested on Intel AI Labs server (16GB DRAM + 128GB PM)
  • Impact: 85 parallel tasks (30% improvement over Intel standard, 85x over DRAM-only); 1.2x speedup with near-DRAM performance using slower PM

Computer Vision & Image Processing

The Pupil Tracker: Fast and Efficient Pupil Segmentation and Tracking

Spring 2022 - CS289 Final Project

  • Problem: Deep learning methods require 4-10 days training time, making them impractical for immediate behavioral analysis
  • Solution: MATLAB-based KNN algorithm with elliptical masks for light reflections and whisker obstructions
  • Implementation: Manual ROI selection → image binarization → KNN-based pupil center/radius detection
  • Impact: 0.075 sec/frame (60x faster than Detectron2, 20% faster than DeepLabCut); eliminated training time; 30 min vs 30+ hours for 27-min video

Diffusion Models & Generative AI

Microscopy Denoising Diffusion with Poisson-Aware Physical Guidance

Work in Progress

  • Problem: Standard diffusion models assume Gaussian noise, but fluorescence microscopy has signal-dependent Poisson noise, causing artifacts and hallucinated details
  • Solution: Poisson-Kullback-Leibler (PKL) guidance replacing L2 norm with KL divergence for physically accurate noise modeling
  • Implementation: Modified diffusion model data consistency term to use Poisson-appropriate statistical metrics; leverages preliminary CNN dataset (~40,000 widefield/2-photon image pairs)
  • Impact: State-of-the-art performance with superior robustness to imperfect optics and reduced artifact hallucination

Machine Learning Tools for Energy Systems

Spring 2021 - ME249

Project 1: Genetic Algorithm for Heat Transfer Correlation

  • Problem: Manual tuning of heat transfer correlations across varying conditions
  • Solution: Genetic algorithms to optimize heat flux-wall superheat constants
  • Implementation: Raw data and dimensionless Rohsenow correlation models
  • Impact: Error <0.04; poor initialization requires 2x more iterations

Project 2: Neural Network Modeling of Spray Cooling and Gas Turbine Systems

  • Problem: Complex thermal systems need sophisticated modeling for nonlinear relationships
  • Solution: Neural networks for spray cooling and gas turbine prediction
  • Implementation: Built from scratch + Keras comparison; ELU vs tanh activations
  • Impact: Spray cooling: error <0.00035; Gas turbine: MAE 0.04 (ELU) vs 0.05 (tanh)

Project 3: Performance Modeling of Solar PV Power Systems

  • Problem: Complex solar panel performance interactions and configuration optimization
  • Solution: Neural networks for power output and configuration prediction
  • Implementation: PCA for key factors; separate power vs configuration models
  • Impact: Power model MAE 0.0018 vs configuration model MAE 0.063 (35x improvement)

Project 4: Solar Thermal Power Plant Boiler and Electronics Cooling

  • Problem: Accurate temperature/quality predictions needed for safe thermal system operation
  • Solution: Neural networks for steam quality, boiler temperature, and component cooling prediction
  • Implementation: Keras models from tube diameter, solar flux, mass flow rate; dropout testing
  • Impact: Boiler MAE 0.0124, electronics MAE 0.0745; dropout worsened performance (MAE 0.024)
